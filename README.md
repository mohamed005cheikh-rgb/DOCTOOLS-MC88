# DOCTOOLS – Client‑Side PDF & Document Toolkit

> **Version 2.0 – Core Edition**  
> 100 % browser‑based – no uploads, no server, no tracking.

---

## 🇬🇧 English

### What is DOCTOOLS?

DOCTOOLS is a lightweight, secure, and fast web application that gives you **16 essential PDF and document tools** directly in your browser.  
All processing happens locally – your files never leave your device. No sign‑up, no ads, no hidden costs.

### Why use it?

- **Privacy‑first** – everything runs client‑side, so your documents stay confidential.
- **Instant** – no waiting for uploads or server queues.
- **Offline‑ready** – once the page loads, you can even work without an internet connection (except for loading external libraries).
- **Free & open** – use it as many times as you like.

### The 16 Tools – At a Glance

| Tool | What it does |
|------|--------------|
| **PDF to JPG** | Extract every page as a high‑quality JPG image (saved as a ZIP). |
| **PDF to PNG** | Same as JPG, but lossless PNG format. |
| **JPG to PDF** | Combine multiple images into a single PDF document. |
| **TXT to PDF** | Turn plain text into a neatly formatted PDF (custom font size). |
| **JSON to PDF** | Generate a structured PDF table from your JSON data. |
| **CSV to PDF** | Convert CSV files (with full support for quotes and multiline cells) into a clear PDF table. |
| **Compress PDF** | Reduce file size by optimising the PDF structure (quality slider). |
| **Watermark PDF** | Add a text or image watermark (logo) to every page. |
| **PDF Signer** | Draw or upload your signature and place it on the first page. |
| **PDF Redactor** | Draw black rectangles over sensitive parts of the document. |
| **Page Organizer** | Reorder, delete, or extract pages – then save the new PDF. |
| **Rotate Pages** | Rotate all pages or selected ones (90°, 180°, 270°). |
| **Add Page Numbers** | Automatically number pages with custom position and start number. |
| **Merge & Split** | Combine multiple PDFs into one, or split a PDF into separate pages (ZIP or individual downloads). |
| **Extract Images** | Pull out every embedded image from a PDF and save them as a ZIP. |
| **Metadata Editor** | View, edit, or wipe the title, author, subject, and keywords of a PDF. |

*(Tools like PDF to Word / Excel / PPT have been removed because they require server‑side processing and would compromise our client‑only philosophy.)*

### When to Use Which Tool

- **You need to embed PDF pages in a presentation or website** → use **PDF to JPG/PNG**.
- **You have scanned paper documents as images** → combine them with **JPG to PDF**.
- **You want to turn notes or reports into a clean PDF** → use **TXT to PDF**.
- **You have data in JSON or CSV format** → generate a table with **JSON to PDF** or **CSV to PDF**.
- **You need to email a large PDF** → compress it first with **Compress PDF**.
- **You want to protect your work with a watermark** → **Watermark PDF**.
- **You need to sign a contract digitally** → use **PDF Signer**.
- **You must hide sensitive information before sharing** → use **Redactor**.
- **You have a PDF with pages out of order** → reorder with **Page Organizer**.
- **Scanned pages are upside down** → fix with **Rotate Pages**.
- **You need page numbers for a report** → use **Add Page Numbers**.
- **You have several PDFs to combine** → use **Merge & Split** (merge mode).
- **You want to extract images from a PDF (e.g., for a blog)** → use **Extract Images**.
- **You need to clean up PDF metadata** → use **Metadata Editor**.

### How to Use

1. Open the DOCTOOLS page in any modern browser (Chrome, Firefox, Edge, Safari).
2. Browse the tool cards – click on any tool you need.
3. A modal window will open. Follow the instructions:
   - Drag & drop a file onto the upload area, or click to browse.
   - Adjust any options (e.g., font size, watermark text, rotation angle).
   - Click the main action button (e.g., “Start Conversion”, “Generate PDF”, “Apply”).
4. The tool will process your file and automatically download the result – nothing is stored.

> **Tip:** You can also drag a file directly onto the main page – DOCTOOLS will try to guess the best tool for that file type.

> **Astuce :** Vous pouvez également glisser‑déposer un fichier directement sur la page principale – DOCTOOLS tentera de deviner l’outil le plus adapté à ce type de fichier.
